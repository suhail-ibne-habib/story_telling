Storytelling · scene index

Recap pipeline

The movie is indexed once: dialogue, shot cuts, and a labelled contact sheet per scene that Gemini describes frame by frame. DeepSeek writes the recap by citing moment IDs from that index, never timestamps. Every clip time comes from the video file.

Open storage/jobs/<jobId>/review/index.html or /inspect.html to watch the result.

movie file + name → 0 metadata → 1 movie index → 2 DeepSeek recap (moment IDs) → 3 TTS → 4 best shot + vision check → 5 assemble

Stage 0

Metadata

FFprobe on the input movie

Input

  • storage/inputs/<filename>

Output

  • metadata/meta_data.json — duration, size, streams

Stage 1

Movie index

Whisper · PySceneDetect · Gemini vision · cached per movie

Input

  • Original movie file

Output (storage/index/<movie>/)

  • subtitles.json — Whisper dialogue with times
  • shots.json — PySceneDetect shot cuts
  • scenes.json — shots grouped into ~15–50s scenes
  • grids_v3/ — one contact sheet per scene: a tile per shot (every 3s in long shots) labelled "#n HH:MM:SS", duplicates dropped, max 16 (4×4)
  • scene_notes_v3.json — Gemini scene summary plus what each tile shows; credits/text frames flagged
  • movie_index.json, index_lines.txt

Stage 2

Recap

DeepSeek · one call per angle · cached scene list

Input

  • Movie name and index_lines.txt
  • Angles, e.g. narrator (default), storyteller, recap, villain, twist, shorts

Output

  • Beats with text, 1–3 moment IDs, and "shows" (what the viewer sees)
  • Checked: IDs exist, no credits frames, forward in time, no reuse (retries with the errors)
  • recap/recaps.json, recap/<angle>.json

Stage 3

Text to speech

Edge TTS · one voice file per beat

Input

  • recap/<angle>.json

Output

  • voice/<angle>/B01.mp3, …
  • voice/<angle>.json — audio and exact duration

Stage 4

Cut

Clip on the cited moment's shot · Gemini checks 3 frames

Input

  • Voice durations, cited moments and their shots
  • Original movie file

Output

  • cut/<angle>/B01.mp4 — clip as long as the voice; a line citing moments from different shots gets one shot per moment (≥ 2s each, max 3), joined in the cited order
  • cut/<angle>.json — chosen shots, score per shot, what was visible, what was tried
  • Pass = the line's subject and action are visible (≥ 7); none pass → DeepSeek rewrites the line to fit the best footage, re-voiced and re-checked

Stage 5

Assemble

FFmpeg · voice on each clip, then join

Input

  • Clips and voice files

Output

  • output/<angle>.mp4
  • review/index.html
